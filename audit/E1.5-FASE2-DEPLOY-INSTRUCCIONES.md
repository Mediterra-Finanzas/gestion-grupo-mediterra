## 3. Comando de deploy (NO ejecutar aún)

```bash
supabase functions deploy osiris-auth --project-ref ipsjsfkmmryzoavyasrx --no-verify-jwt
```

- `--no-verify-jwt`: la función hace su **propia** autenticación (email+PIN), así que no debe exigir un JWT válido en el request (el cliente la llama antes de tener sesión).
  - *Persistencia opcional:* en vez del flag, se puede fijar en `supabase/config.toml`:
    ```toml
    [functions.osiris-auth]
    verify_jwt = false
    ```
